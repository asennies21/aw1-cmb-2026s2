Comandos Node

Una sola vez en sus compus:

- Instalar NodeJS version estable LTS
- verificar si se instalo con:

-verificar version:
node -v

-verificar version de npm:
npm -v

- Instalar pnpm (en el aula):
npm i -g pnpm

En cada proyecto:

- Inicializar proyecto en la ruta que quiero iniciar el desarrollo:
pn init
(crea el documento package.json)

- Instalar un paquete:
- https://www.npmjs.com/
- https://pnpm.io/es/
pn add five-server

- Creacion de .gitignore para ignorar node_modules y no se suba al repo (no le hacemos seguimiento)
- para volver a instaler lo que figura en package.json:
pn install

- Configurar script "dev": "five-server" en el archivo package.json
pn dev
